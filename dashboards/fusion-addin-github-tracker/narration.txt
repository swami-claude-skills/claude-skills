This is the skill sheet for the Fusion Add-in GitHub Tracker, the skill that builds a tracker page for taking one Fusion add-in to its own public GitHub repo

Section one, Dashboard Summary. A short intro and a table of every section.

Section two, Search. Type a few words to find anything on this page, in any order and with small typos forgiven. Narrow the results with filters, and click a result to jump to it.

Section three, What It Is. It has two paths: move, for an add-in that already exists, and new, for one built in its repo from day one. Every step has a copyable prompt and a done tick saved in the page's own database.

Section four, What It Does. It gets the tracker kit from Swami's private repo, writes a small settings file, builds and patches the page, checks it in a browser, adds the audio overview, runs the privacy scan, and publishes it.

Section five, How to Use It. Ask for a tracker in the add-in's Claude project, answer any questions, add the tracker link to the project instructions, then work through the steps and tick each one when it's done.

Section six, Skills It Depends On. Other skills it calls or hands off to.

Section seven, Programs It Depends On. Software outside Claude and where it runs.

Section eight, Capabilities and Limitations. What it can and cannot do.

Section nine, Scheduled Tasks. Whether it needs or sets up scheduled tasks.

Section ten, Where It Runs. Which Claude it runs in, plus notes for other AIs.

Section eleven, Gotchas. The first public release always includes the update check, and the update banner tests only work from the second release.

Section twelve, Other Requirements. Accounts, settings, hardware and access it needs.

Section thirteen, Card and Freshness. Which version of the skill this page describes.

Section fourteen, Mind Map. The whole page as bubbles you can open, hover for a summary, and click to jump to that spot.

Section fifteen, Glossary. The terms used on this page, each linked to where it appears.

Section sixteen, Source Document, Verbatim. The skill's own instructions, word for word. It opens formatted, and you can switch it to plain text.
