This page is the skill sheet for the YouTube comments skill. It gets every comment and reply on a YouTube video with the free tool why-tee-dee-ell-pee, or Swami's YTX shortcut on a Mac or Windows PC, then turns them into threads for analysis or a vibe dashboard.

Section one, Dashboard Summary. A short intro and a table of every section.

Section two, Search. Type a few words to find anything on this page, in any order and with small typos forgiven. Narrow the results with filters, and click a result to jump to it.

Section three, What It Is. What the skill is, and why it exists: copying comments by hand once caught only seventy five of four hundred and seventy four.

Section four, What It Does. Eight things it handles, from ready to paste commands and full extraction, to stats, a threaded text file, a dashboard, a table, an export, and a browser fallback.

Section five, How to Use It. What to ask for, then six steps on the Mac: ask, install once, [extract](/ɪkstɹˈækt/) with YTX or why-tee-dee-ell-pee, [upload](/ʌplˈoʊd/) the file, let Claude process it, and choose the hand off. A second table gives the same steps on Windows, with the PowerShell version of YTX.

Section six, Skills It Depends On. None are required. The vibe dashboard skill is used for dashboards, the XLSX skill for spreadsheet exports, and the YouTube transcript skill is a related sibling that explains how to install YTX.

Section seven, Programs It Depends On. Why-tee-dee-ell-pee and Swami's YTX shortcut, which now has a PowerShell version for Windows, plus Terminal or PowerShell, Python in Claude's workspace, and optionally [Deno](/dˈiːnoʊ/) and a web browser. Each program has macOS and Windows install notes.

Section eight, Capabilities and Limitations. It gets the complete comment tree with no API key. But Claude's cloud workspace can't reach YouTube, comment counts drift, YouTube changes can break older versions, and the Windows YTX is new and not yet tried on a real PC.

Section nine, Scheduled Tasks. None. The skill runs only when asked.

Section ten, Where It Runs. It works in any Claude app session with code execution on, and best in the desktop app linked to the Mac. A linked Windows PC, Claude Code, and other AI assistants are not tested; Swami tests in Claude only.

Section eleven, Gotchas. Fourteen traps, the biggest being that a reply depth of one silently drops every reply. Four are for Windows, and one covers a missing [Deno](/dˈiːnoʊ/).

Section twelve, Other Requirements. A Mac running macOS ten fifteen or newer, or a Windows ten or eleven PC, plus code execution, a way to [upload](/ʌplˈoʊd/) the file, and internet on the computer.

Section thirteen, Card and Freshness. Which version of the skill this page describes and its fingerprint.

Section fourteen, Mind Map. The whole page as bubbles you can open, hover for a summary, and click to jump to that spot.

Section fifteen, Glossary. The terms used on this page, each linked to where it appears.

Section sixteen, Source Document, Verbatim. The skill's own instructions, word for word.
