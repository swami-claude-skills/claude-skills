This page is the skill sheet for the skill dashboard skill. It creates, [updates](/ʌpdˈeɪts/), checks and publishes a skill sheet: a vibe dashboard page explaining one of Swami's own skills, built from a skill card with a fingerprint that shows when the page is out of date

Section one, Dashboard Summary. A short intro and a table of every section.

Section two, Search. Type a few words to find anything on this page, in any order and with small typos forgiven. Narrow the results with filters, and click a result to jump to it.

Section three, What It Is. Every one of Swami's skills gets a sheet in a fixed shape, rendered from a card. The card's fingerprint changes whenever the skill does, and nothing goes public until Swami says publish.

Section four, What It Does. Nine jobs: create, [update](/ʌpdˈeɪt/), check and publish, the fixed sections, both Mac and Windows, open questions, the registry, and the privacy scan.

Section five, How to Use It. Eight steps: ask, then Claude writes the card, builds, [records](/ɹᵻkˈɔːɹdz/), checks and publishes a private draft. Swami vets it and says publish. On Windows the steps are the same.

Section six, Skills It Depends On. Vibe dashboard is required for the template, patches and audio. Artifact sharing audit is related, because it uses the same fingerprint.

Section seven, Programs It Depends On. Only a browser on your computer. Python, git, a headless browser and the [Kokoro](/kˈoʊkoʊɹoʊ/) voice run in Claude's workspace, and GitHub Pages serves the published sheets.

Section eight, Capabilities and Limitations. It stays current with vibe dashboard, flags stale pages, and keeps drafts rebuildable. But it works one skill at a time, only on Swami's skills, and never claims what nobody has tried.

Section nine, Scheduled Tasks. None of its own. The skill library's nightly refresh reads its registry to link each sheet and flag stale ones.

Section ten, Where It Runs. It runs in Claude's cloud sessions and in the desktop app on Swami's Mac, where every sheet so far was made. The other surfaces are untested.

Section eleven, Gotchas. Seven traps, from duplicate drafts, curly braces and capturing groups in cards to file paths, checking published pages, the capability warning, and fixing stress in the card.

Section twelve, Other Requirements. GitHub access to the claude skills repo, code execution with network access, Swami's memory of who is under NDA, and any Mac or Windows computer with a browser.

Section thirteen, Card and Freshness. Which version of the skill this page describes, and its fingerprint. There are no open questions.

Section fourteen, Mind Map. The whole page as bubbles you can open, hover for a summary, and click to jump to that spot.

Section fifteen, Glossary. The terms used on this page, each linked to where it appears.

Section sixteen, Source Document, Verbatim. The skill's own instructions, word for word.
